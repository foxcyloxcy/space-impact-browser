## Capture protocol
For each stage review beginning, middle, last wave and boss on an original-hardware recording. Record timestamp, approximate normalized ship/enemy x/y, sprite silhouette, enemy wave order, scroll speed, pickups, attack spread, lives and weapon count. Use two independent references for contested details. Obtain permission before reproducing extracted assets or audio. In new level data distinguish `verified`, `approximate`, and `unverified`. We should not invent exact boss characteristics from the game title alone.

## Current status
Eight stage transitions exist in the prototype but are generic and time-gated. No original stage wave layouts, backgrounds, enemies, or boss attack sequences are verified as matching the recordings. The matrix is the source inventory for the faithful gameplay phase.
